# SmartClinic Overview

SmartClinic is a premium full-stack platform designed to revolutionize clinic management through AI-driven wait-time predictions and seamless patient triage.

## Technical Stack
- **Backend**: Node.js (Express)
- **Frontend**: HTML5, Vanilla JS, CSS3 (Glassmorphism)
- **ML Service**: Python (Flask, Scikit-learn)
- **Database**: Firebase Firestore
- **Deployment**: Microsoft Azure, Render.com, Google Cloud Platform

For detailed guides, please refer to the [Main Documentation HUB](./README.md).
