# SmartClinic Sprint User Stories, UATs and Tests

The following tables organise each sprint using the structure: User Story, UATs, Related Test File, and How The Test Relates.

## Sprint 1

| User Story | UATs | Related Test File | How The Test Relates |
| --- | --- | --- | --- |
| 1. Viewing Availability<br><br>As a Patient, I want to select a specific date on a clinic's calendar so that I can see the available time slots for that day. | Given I am viewing a selected clinic<br>When I select a valid future date on the clinic calendar<br>Then I should see available time slots for that clinic on that date. | appointmentsController.test.js, availability.test.js, firebaseService.test.js | Tests check that availability slots are returned for a date, closed clinics return empty slots, operating hours affect slots, and failures are handled. |
| 2. Finding clinic | Given I am on the clinic search page<br>When I type Yeoville and click search<br>Then I see a list of matching clinics<br><br>Given I am on the clinic search page<br>When I click Use My Location and allow access<br>Then I see clinics sorted by distance from me<br><br>Given I am on the clinic search page<br>When I type something that matches no clinic<br>Then I see a "No clinics found" message. | clinicsController.test.js<br><br>Closest: clinicsController.test.js | getClinics tests check that clinics are fetched from the Google API based on search input.<br><br>Tests support location-based search queries but do not fully prove browser location permission or frontend distance sorting.<br><br>API success/failure is tested, but no direct test exists for showing "No clinics found". |
| 3. Appointment booking<br><br>As a patient I can book an appointment so I can receive care at a specific time. | Given I am a registered patient<br>When I select a clinic, date, and available time slot<br>Then the system should create the appointment and confirm the booking<br><br>Given a time slot is already booked<br>When I try to book the same slot<br>Then the system should prevent the booking and return an error<br><br>Given I select a past date<br>When I try to book an appointment<br>Then the system should reject the request. | appointmentsController.test.js, firebaseService.test.js, emailservices.test.js<br><br>firebaseService.test.js, appointmentsController.test.js<br><br>Closest: appointmentsController.test.js, firebaseService.test.js | Tests verify appointment creation, clinic metadata usage, and confirmation emails.<br><br>Tests validate duplicate booking and full-slot errors.<br><br>Existing validation tests exist, but past-date rejection appears missing. |
| 4. Rescheduling appointment | Successfully reschedule an appointment<br>Given the patient is logged in and has an upcoming appointment<br>When the patient selects the appointment, chooses a new available time slot, and confirms the change<br>Then the system should update the appointment and display the new booking details<br><br>Attempt to reschedule to an unavailable slot<br>Given the patient is logged in and is rescheduling an appointment<br>When the patient selects a time slot that is no longer available<br>Then the system should prevent the update and display an error message. | appointmentsController.test.js, firebaseService.test.js, queueService.test.js<br><br>queueService.test.js, queueController.test.js | Tests cover cancelling old appointments, creating rescheduled appointments, and queue syncing.<br><br>Tests reject full slots, locked items, and out-of-hours scheduling. |
| 5. Cancel appointment<br><br>As a Patient, I want to click a 'cancel' button on an upcoming appointment and confirm my choice so that I can free up the slot for another patient if I can no longer attend. | Successfully cancel an appointment<br>Given the patient is logged in and has an upcoming appointment<br>When the patient clicks the cancel button and confirms the cancellation<br>Then the system should cancel the appointment and remove it from the list of upcoming bookings<br><br>Cancel action not confirmed<br>Given the patient is logged in and has selected an appointment to cancel<br>When the patient clicks the cancel button but does not confirm the cancellation<br>Then the system should keep the appointment unchanged. | appointmentsController.test.js, firebaseService.test.js, emailservices.test.js<br><br>Closest: appointmentsController.test.js | Tests ensure cancellation succeeds and cancellation emails are sent.<br><br>Backend cancellation is tested, but frontend confirmation dismissal is not directly tested. |
| 6. Viewing existing bookings | Given I am a logged-in patient<br>When I open my bookings page<br>Then I should see my existing upcoming appointments. | appointmentsController.test.js, firebaseService.test.js | Tests cover retrieving appointments and handling invalid requests. |

## Sprint 2

| User Story | UATs | Related Test File | How The Test Relates |
| --- | --- | --- | --- |
| Clinic Staff log in and registration<br><br>As a clinic staff, I want to log in using a third party identifier provider to securely manage the queue. | Given I am clinic staff with a valid invite, when I register/login, then I am linked to the clinic and redirected to the staff dashboard. | UserController.test.js, adminStaffWorkflow.test.js, firebaseService.test.js | Tests cover staff profile creation, invite validation, approvals, and dashboard redirects. |
| Admin login and registration<br><br>As an admin, I want to log in using a third party identifier provider to securely manage clinics. | Given I have a valid admin code, when I register/login as admin, then I am linked to a clinic and redirected to the admin dashboard. | UserController.test.js, firebaseService.test.js | Tests cover admin registration, clinic claiming, and invalid code rejection. |
| Manage Clinic operating hours<br><br>As an admin, I want to set and update operating hours for each facility so that patients can only book appointments within valid time slots. | Given I am the clinic admin, when I update operating hours, then availability only shows slots inside those hours. | clinicsController.test.js, firebaseService.test.js, queueService.test.js | Tests verify operating-hour updates and availability filtering. |
| Add clinic<br><br>As a system administrator I want to add clinics to the system so an admin can be assigned to it. | Given I am a system admin, when I add a clinic with valid details, then the clinic is created and can be assigned to an admin. | clinicsController.test.js, firebaseService.test.js | Tests cover creating clinics and preventing duplicates. |

## Sprint 3

| User Story | UATs | Related Test File | How The Test Relates |
| --- | --- | --- | --- |
| Clinic Management<br><br>As an admin, I want to manage the services offered at a facility so that patients can find a clinic that meets their healthcare needs. | Given I am an admin, when I add/update/delete clinic services, then patients can see the correct services for that clinic. | clinicsController.test.js | Tests cover adding, updating, deleting, and retrieving services. |
| Filter clinics<br><br>As a patient, I want to filter clinics using different criteria so that I can find a suitable clinic quickly.<br><br>Types:<br>As a patient, I want to filter clinics by facility type so that I can choose the kind of healthcare facility I need.<br>As a patient, I want to filter clinics by services offered so that I can find clinics that provide the care I require.<br>As a patient, I want to filter clinics by location (province, district, and region) so that I can find clinics near me. | Given I am on the clinic search page, when I filter by facility type, then only matching facilities are shown.<br><br>Given I filter by a service, when clinics are shown, then only clinics offering that service are listed.<br><br>Given I select province, district, and region filters, when I search, then clinics in that area are shown. | Closest: clinicsController.test.js<br><br>Closest: clinicsController.test.js<br><br>Closest: clinicsController.test.js | Facility type exists in clinic profiles, but direct filtering tests are missing.<br><br>Service management is tested, but patient-facing filtering is not directly covered.<br><br>Region fields exist, but filtering functionality is not fully tested. |
| Staff assignment<br><br>As an admin, I want to assign a staff member to a clinic so that they can manage patients and queues at that facility. | Given I am an admin, when I invite/approve staff for a clinic, then that staff member can manage that clinic. | adminStaffWorkflow.test.js, UserController.test.js | Tests cover staff invites, approvals, and removals. |
| Update Patient Status<br><br>As a clinic staff member, I want to update patient statuses so that I can track where each patient is in the consultation process. | Given I am clinic staff, when I update a patient status, then the queue item is updated and the patient can be notified. | queueController.test.js, queueService.test.js, emailservices.test.js | Tests validate queue status updates and notification sending. |
| Add or Reschedule Patients<br><br>As a clinic staff member, I want to add new patients or reschedule existing appointments so that the daily schedule remains accurate and flexible. | Given I am clinic staff, when I add or reschedule a patient, then the queue and appointment details are updated correctly. | queueController.test.js, queueService.test.js | Tests cover adding queue items, validation, and rescheduling. |
| Set Staff Availability<br><br>As clinic staff, I want to set my availability so that the system can schedule patients only when I am available. | Given I am clinic staff, when I set my availability, then the system stores it and uses it in reporting/scheduling. | setAvailability.test.js, clinicService.test.js | Tests verify saving, retrieving, and using staff availability data. |

## Sprint 4

| User Story | UATs | Related Test File | How The Test Relates |
| --- | --- | --- | --- |
| Receive queue turn notifications<br><br>As a patient, I want to receive notifications when my turn is approaching so that I can arrive at the consultation area on time. | Given I am in the queue, when my status changes or my turn approaches, then I receive a notification. | queueController.test.js, emailservices.test.js | Tests verify notification sending and queue status emails. |
| Join virtual walk-in queue<br><br>As a walk-in patient, I want to join a virtual queue when I arrive at the clinic so that I can wait remotely and avoid standing in physical lines. | Given I arrive at a clinic, when I join the walk-in queue, then I am added to the queue with an available slot. | queueController.test.js, queueService.test.js | Tests validate queue item creation and slot assignment. |
| View queue position and wait time<br><br>As a patient, I want to see my queue position and estimated wait time in real time so that I know when I will be assisted. | Given I am in the queue, when I view my queue status, then I see my position and estimated wait time. | patientQueueService.test.js, queueController.test.js | Tests cover queue position and wait-time calculations. |
| View clinic performance analytics and reports<br><br>As an admin, I want to view analytics and reports such as average patient wait times by clinic and time of day, appointment no-show rates, and custom report views so that I can monitor clinic performance and improve operational efficiency. | Given I am an admin, when I request analytics for a date range, then I see wait-time and no-show report data. | adminStaffWorkflow.test.js, firebaseService.test.js, clinicService.test.js | Tests cover reports, validation, utilisation, and workload analytics. |
